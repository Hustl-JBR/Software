# Codex implementation roadmap

1. Complete the current recovery: verified employee Operations experience, migrations, test matrix, Railway staging deploy, persistence proof, and draft PR.
2. Implement reviewed employee invitation/provisioning and credential enrollment; separately complete backup/restore readiness.
3. Validate one full synthetic shipment lifecycle and define only the missing authoritative transitions/evidence.
4. Select document-security requirements and provider before implementing storage.
5. Evaluate one provider integration at a time from official documentation, beginning only after the core workflow is stable.

Customer portals, public APIs, EDI, load boards, live tracking, compliance providers, accounting, payments, Supabase database/Auth, and production infrastructure are not part of phase 1.
