# Product reset

Atlas is an employee freight-operations system, not a developer console and not an autonomous broker. The first useful loop is reviewed intake → approved draft load → ownership/readiness → quote and carrier evidence → appointments, communications, tasks, and audit. Humans own consequential decisions.

The product reset prioritizes understandable persisted workflows before portals, APIs, integrations, analytics breadth, or automation. Existing capabilities are retained and reorganized; this is not a rebuild.
