# Information architecture

The primary hierarchy is Operations → organization command center → Loads/Tracking/Network/Documents/Analytics/Settings → a specific load record. New Shipment is the singular creation action. Record tabs group Overview, Stops, Tracking, Carrier, Contacts, Communications, Documents, Tasks, Timeline, Audit, Financials, Pricing, and Sourcing.

Technical synthetic controls live outside this hierarchy at `/internal/staging-tools`. Timeline is employee language; Audit is technical accountability. Employee screens never expose database model or raw enum names.
