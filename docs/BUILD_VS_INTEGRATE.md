# Build versus integrate

Build Atlas-specific workflow, authorization, evidence, human approvals, exception handling, audit, and the operator experience. Integrate commodity infrastructure and regulated/market data only after provider selection: identity delivery, object storage, messaging transport, carrier authority, tracking, load boards, accounting, and payments.

Selection requires official API review, coverage, data rights, security, uptime/failure semantics, sandbox quality, cost, exportability, and exit strategy. No provider integration is implemented in this phase.
