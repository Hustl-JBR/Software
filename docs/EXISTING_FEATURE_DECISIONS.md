# Existing feature decisions

- Preserve the real Prisma/PostgreSQL path and the isolated browser demo.
- Keep Better Auth; public sign-up stays disabled.
- Keep exact-revision approval, creator/approver separation, idempotency, tenant scope, and append-only audit.
- Explicit role rows are authoritative.
- Staging shows only persisted or calculated facts; demo values are labeled synthetic.
- Money persists as integer cents but employees enter dollars.
- Carrier selection and driver assignment remain separate.
- Documents and all third-party integrations remain inactive until separately approved.
